## Descripción

DocFitness es una herramienta para profesionales de nutrición y entrenamiento que permite:

- Crear perfiles de pacientes
- Generar planes nutricionales con base de datos de alimentos
- Crear rutinas de entrenamiento con calendario semanal
- Generar documentos HTML compartibles vía link
- Seguimiento de evolución con métricas

## Stack técnico

- React 18 + Vite
- TypeScript
- Tailwind CSS
- @react-pdf/renderer
- lz-string (compartir URL)

## Instalación

```bash
npm install
npm run dev
```

## Build

